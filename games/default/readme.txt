Oneshot v1.03
=============

Synopsis
--------

Oneshot is an RPG Maker 2003 Puzzle/Adventure game where you, as the player, must guide a lost child through a strange world, utilizing items, characters, and the environment to progress.

Features
--------

 - Original soundtrack
 - Custom graphics
 - Unusual gameplay features
 - Permanent consequences

Controls
--------

 - Arrow Keys/hjkl:     Move character/cursor
 - Z/Space/Enter:       Action/Confirm
 - X/N/B/Esc:           Menu/Cancel
 - Shift:               Deactivate current item
 - Any number key:      Show/hide fast travel menu (outdoors only)
